All notable changes to this project will be documented in this file.

## [Unreleased]

### Added
- Configuração inicial do projeto com Vite, React e TypeScript
- Configuração do Chakra UI para estilização
- Configuração do React Router para navegação
- Configuração do React Query para gerenciamento de estado do servidor
- Configuração do Formik e Yup para formulários e validação
- Configuração do ESLint, Prettier e Husky para padronização de código
- Estrutura de pastas e componentes iniciais
- Páginas iniciais: Home, Usuários, Eventos, Apostas e Configurações
- Componentes reutilizáveis: Card, DataTable, Formulários, etc.
- Suporte a temas claro/escuro

### Changed
- Atualizadas as configurações do TypeScript para melhor suporte ao React
- Melhorada a organização dos estilos globais

### Fixed
- Corrigidos problemas de tipagem nos componentes
- Corrigidos avisos do ESLint
