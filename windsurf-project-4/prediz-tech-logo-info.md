# 🚀 prediz.tech - Logo Design System

## 📋 Logo Specifications

### **Design Concept**
- **Minimalist, futuristic logo icon** for "prediz.tech"
- **Stylized abstract letter "P"** with upward-trending arrow
- **Integrated circuit board lines** and data points
- **Web3 aesthetic** with clean, high-tech vector art

---

## 🎨 Color Palette

### **Primary Colors**
- **Electric Purple**: `#A020F0`
- **Neon Violet**: `#8B00FF`

### **Background**
- **Deep Charcoal Dark**: `#0A0F1A`

### **Gradient Direction**
- **Linear gradient** from Electric Purple (0%) to Neon Violet (100%)
- **Applied to all logo elements** for consistency

---

## ✨ Visual Effects

### **Neon Glow**
- **Soft glow effect** with Gaussian blur (stdDeviation: 3-4)
- **Creates high-tech, futuristic appearance**
- **Enhances visibility** against dark background

### **Circuit Board Elements**
- **Glowing circuit lines** connecting data points
- **Minimalist tech pattern** suggesting connectivity
- **Data points** at circuit intersections (1.5-2px radius)

---

## 📐 Logo Components

### **Main Letter "P"**
- **Vertical stem**: Clean, bold line
- **Upper curve**: Smooth, flowing arc
- **Integrated arrow**: Upward-trending element
- **Stroke width**: 2.5px for main elements

### **Tech Elements**
- **Circuit paths**: 0.8px stroke width
- **Data points**: Circular nodes (1.5px radius)
- **Tech squares**: Small rectangles (8x8px)
- **Connection lines**: Subtle linking elements
