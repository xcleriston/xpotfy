### **Passos:**
1. Abra o arquivo `proposta-estudio33.html` no navegador
2. Pressione `Ctrl + P` (Windows) ou `Cmd + P` (Mac)
3. Selecione "Salvar como PDF"
4. Configure:
   - **Layout**: Retrato
   - **Margens**: Nenhuma
   - **Fundo gráfico**: Marcado
5. Clique em "Salvar"

## 🔧 **SOLUÇÃO DE PROBLEMAS**

### **Problemas Comuns:**

#### **❌ PDF não gera:**
```bash
# Verificar instalação
pip show weasyprint

# Reinstalar se necessário
pip uninstall weasyprint
pip install weasyprint
```

#### **❌ Estilos não aparecem:**
- Verifique se o navegador suporta CSS moderno
- Use Chrome/Firefox mais recentes
- Limpe cache do navegador

#### **❌ Formatação incorreta:**
- Verifique encoding UTF-8
- Use navegador atualizado
- Tente método alternativo
